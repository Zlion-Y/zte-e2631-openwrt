# 45 — R4d：TXD 位级装配解码（mtf_write_tmac_info_fixed_rate）（2026-10-31）

## 1. 链条闭合

```
write_tmac_info_offload_pkt(0x1B05E8)  构建 52B TMAC 模板（doc 44 布局）
→ asic_write_tmac_info_fixed_rate(0x142404) = arch_ops[396] 分发
→ mtf_write_tmac_info_fixed_rate(0x1B3018) = MT7916 PCI 实现（真 TXD 装配器）
→ 输出 4 个 TXD 双字（16B TXD），入数据环，pci_kick_out_data_tx 门铃
```

arch_ops[396] 由 mt7916_init @1a0940 填（vtbl-full.map r5[396]）。

## 2. TXD 位级装配（r5=52B 模板，已核指令）

**word 0（r3 累加）**：
- `ldrh r3,[r5]` = 模板 +0 u16（低 16 位区）
- 速率分支常数 `0x1C50` / `0xBAB0`（orr 进低区——定速率编码）
- 模板 +44 → `orr #0x1800000`（bits 23-24 区）
- sta/wtbl+60 → `orr r0,lsl #25`（bit 25+）
- 模板 +25 → `orr lsl #11`；+13 → `orr lsl #20`
- 模板 +41 → `orr lsl #24`；**bit31 置位**（owner/valid 类）
- 条件位 `#0x20000` / `#0x60000`（模板 +25 分支）

**word 1（r2 累加）**：
- 模板 +50 → `orr lsl #16`（bits 16-23）
- 模板 +48 → `orr lsl #24`（bits 24-31）
- 模板 +5 → 低区 `orr #0xF800` / `#0x7800`（分支）+ `#1`/`#2` 位
- `bic #1056964608`（0x3F000000 清除高位区）
- 模板 +49 → 位区；`orr #0x80000000`（条件）

**word 2/3**：位打包序列同构（+34/+9/+33/+10/+40/+29/+24/+28 等模板字段），
逐位映射继续 R4e。

## 3. 语义对照（mt76 connac2 命名参考，vendor 指令为准）

word0 高区 = format/own/long 系（bit31 = 模板填充后置位）；word1 高区 =
wcid/目标队列类（+48/+50 即 doc 44 的 +48=sta+3528 typed、+50）。低区常数
分支 = 定速率编码（0x1C50/0xBAB0 与模板 +5 的组合）。

## 4. 边界

- word2/3 逐位映射 = R4e；完整 TXD 构造器（含 wcid 取值）需 P5 AP 状态；
- 未刷机；本次无固件行为变更（data-tx 打印更新 + 版本 2.2）。

## 5. R4e 增补（同日）：TXD 字落点 + 速率参数结构

后半段（0x1B3254-0x1B3340）解出 **TXD 字的实际落点**（r4 = TXD 输出区）：

| TXD 字 | 位/来源 | 含义（推断标注） |
|---|---|---|
| r4+12 | bit31 置位；模板 +14 u12 → bits 16-27 | 长度/标志字（[实测-静态]） |
| r4+20 | 模板 +46→bit9(#512)、+45→bit10(#1024)、+12 原值 OR、+47→bit14(#16384) | 控制标志字 |
| r4+24 | r6[0] bit6→#2048、r6[1] bit1→lsl14、r6[1] bits5-3→速率域、r6[0] bits0-5→#4 组合 | **速率参数字**（r6 = 定速率参数结构：bits5-3=phy mode、bits0-5=MCS/rate、bit6=标志） |

r6 结构（速率参数）：byte0 bits0-5=MCS/rate 索引、byte1 bit1=标志、
byte1 bits5-3=phy mode（sxtb 判负 → 特殊分支 0x1B3474）、byte0 bit6=前导。

剩余：r4+0/+4/+8 三个字的来源（函数更前段）= R4f；r4 缓冲与
`pci_kick_out_data_tx` 的衔接（skb 头布局）待真机首帧对照。

## 6. R4f 增补（同日）：TMAC→TXD 映射闭环

- **dw1 bit13**（#8192）：r7+465 标志字节非零时置位（1b339c）；
- **r4+24 速率字**：`mtf_tx_rate_to_tmi_rate`(1b3340) 的返回值 lsl16 OR
  进 bits16+——**TMI 速率编码**（与 mt76 connac2 TXD rate 字段同位域）；
- **r4+28**：模板 +30→lsl11、+34→lsl16、+33→lsl20（1b335c/1b3368/1b3374）；
- **定速率特殊路径**（asic_write_tmac_info_fixed_rate 分支内部）：
  模板 +43→bit5、r8+2949→lsl24、常数 #20480/#4、+34/+33 移位组合
  （1b33d4-1b3488）；
- 函数主体在 1b337c 收尾（pop），其后为定速率分支内部；
- **skb 衔接**：r4 = skb push 后的 TMAC 区；环描述符引用 skb 数据
  （pci_init_txrx_ring_mem 布局）；kick = CPU_IDX 写 +8。

TMAC→TXD 映射闭环达成：52B 模板 → 16B+ TXD 的全部位路径已可离线追溯。
剩余 = P5 AP 状态（wcid/加密密钥）才能构造真实帧。
